# ADR 0003 — 별칭 사전은 시드 + 생성본으로 구성한다

- 상태: **채택**
- 날짜: 2026-11-04

## 맥락

ADR 0002 는 교차언어 매칭의 보조 신호로 개체 별칭 사전을 쓰기로 했고, "손으로 관리해야 하는 유지보수 부채"라고 적어 두었습니다. 실제로 쓰기 시작하자 그 부채가 두 가지로 구체화되었습니다.

**규모.** 세계 뉴스에 반복 등장하는 고유명사는 국가·지도자·기구·분쟁지역을 합쳐 수천 개입니다. 각각에 7~9개 언어 표기를 손으로 붙이면 만 줄 규모가 되고, 작성자가 자신 없는 언어(러시아어·프랑스어 표기 등)를 추측으로 채우게 됩니다. **틀린 표기는 빈 표기보다 나쁩니다** — 오탐이 공백 판정 점수로 바로 들어갑니다.

**부패.** `kind: person` 항목은 선거와 정변으로 무효화됩니다. 국명도 개칭됩니다(Turkey → Türkiye). 손으로 관리하는 사전은 조용히 썩고, 썩었다는 사실이 드러나지 않습니다.

## 결정

사전을 두 층으로 나눕니다.

**생성본** `aliases.generated.yaml` — Wikidata 에서 생성합니다. Wikidata 는 바로 이 데이터(다국어 레이블 `rdfs:label` 과 별칭 `skos:altLabel`)를 이미 갖고 있고, 새 지도자가 취임하면 며칠 안에 반영됩니다. `scripts/build_aliases_from_wikidata.py` 가 주권국가·국제기구·국가원수/정부수반을 받아 같은 스키마로 씁니다. 커밋하지 않고 주기적으로 재생성합니다.

**시드/오버라이드** `aliases.yaml` — 손으로 씁니다. 112개 개체, 933개 표기. 범위를 좁게 유지합니다:
- Wikidata 에 없거나 레이블이 부실한 항목 (분쟁지역, 해협, 운하 등)
- 언론이 실제로 쓰는 표기가 백과사전 레이블과 다른 경우 (特朗普/川普, 朝鲜/北韓)
- 생성본의 잘못된 표기를 덮어쓸 때

`load_aliases("aliases.generated.yaml", "aliases.yaml")` 로 합쳐 읽습니다. id 충돌은 조용히 덮어쓰지 않고 **오류로 드러냅니다** — 어느 쪽이 이겼는지 모르는 상태가 더 나쁩니다.

## 매칭 규칙도 함께 결정한다

초기 구현은 단순 부분 문자열 일치였고, 짧은 라틴 표기에서 무너졌습니다.

```
"US"  → us, thus, crust
"UN"  → 프랑스어 관사 un, under
"WHO" → 의문사 who
"EU"  → 로마자 eu
```

그래서 표기의 문자 체계와 길이에 따라 방식을 달리합니다.

| 표기 | 방식 |
|---|---|
| 비라틴 (한글·가나·한자·키릴) | 부분 문자열, 소문자화. 최소 2자 |
| 라틴 5자 이상 | 라틴 단어 경계, 대소문자 무시 |
| 라틴 4자 이하 | 라틴 단어 경계, **대소문자 구분** |

단어 경계는 `\b` 가 아니라 라틴 문자·숫자 lookaround 로 구현합니다. `\b` 는 `U.S.` 처럼 구두점으로 끝나는 표기에서 어긋나고, `\w` 는 가나·한자를 포함해 일본어 문장 속 라틴 단어를 놓칩니다.

키릴 표기에 부분 문자열 일치를 쓰는 것은 **이득**입니다 — 러시아어 굴절형(Путина, Путину)이 자동으로 잡힙니다.

## 결과

**좋은 점.** 손으로 쓸 분량이 수천 개에서 100여 개로 줄었고, 인물 항목의 부패를 재생성으로 해결할 수 있습니다. 작성자가 자신 없는 언어를 추측으로 채우지 않아도 됩니다.

**나쁜 점.** Wikidata 는 공개 위키이므로 레이블이 훼손될 수 있습니다. 생성본은 **입력 데이터이지 지시가 아닙니다.** 로더의 검증(최소 길이, 모호 표기 거부)이 1차 방어선이고, 시드 오버라이드가 2차입니다. 외부 엔드포인트 의존이 하나 늘었지만, 수집 파이프라인이 아니라 오프라인 생성 단계에만 걸립니다.

**남은 제약.** 일반 주제어(관세·휴전·선거·지진)는 사전에 넣지 않습니다. 넣으면 모든 관세 기사가 서로 매칭되어 신호가 무의미해집니다. `tests/test_aliases.py::test_seed_has_no_generic_topic_words` 가 이를 검사합니다.

## 구현

- `src/blindspot/aliases.py` — `AliasIndex`, `load_aliases`, 문자 체계별 매칭
- `aliases.yaml` — 시드 112개 개체 (국가 63, 기구 23, 지명 14, 인물 12)
- `scripts/build_aliases_from_wikidata.py` — 생성기 (네트워크 필요, 미실행)
- `tests/test_aliases.py` — 오탐 8건·정탐 7건을 고정, 4개 언어 교차 매칭 확인
