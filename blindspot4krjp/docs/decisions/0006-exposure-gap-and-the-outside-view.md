# ADR 0006 — 노출 격차와 외부 시선

- 상태: **채택**
- 날짜: 2026-11-04
- ADR 0005 의 AND 판정을 **대체한다**

## 맥락

사용자가 문제를 다시 진술했습니다. 핵심은 두 가지가 섞여 있었다는 것입니다.

> "외국 뉴스를 본다고 쳐도 한국언론이나 일본언론에서 이미 한번 보도경향성이라는
> 거대한 필터에 걸러지고 정제된 것을 보게 되잖아요. 그 바깥의 날것에 해당하는
> 세계의 정보를 접하자는 거죠… 무슨 주제가 됐든 말이죠"

두 결핍은 다릅니다.

**누락** — 아예 오지 않은 것.
**굴절** — 왔지만 안쪽 필터에 휘어서 온 것.

지금까지의 설계는 누락만 다뤘습니다. 그리고 **굴절을 적극적으로 억제했습니다** — 안쪽이 다룬 사건은 "공백 아님"으로 메인 목록에서 떨어졌는데, 굴절이 가장 심한 것은 정확히 **크게 보도된 사건들**입니다. 들어본 적 있는 그 형태가 이미 휜 것입니다.

ADR 0005 의 AND 판정도 이 틀에서 나온 것이고, 사용자는 국가 구분이 불필요하다고 지적했습니다 — 어느 쪽이 다뤘는지가 아니라 **내가 접하기 쉬웠는지**가 문제이기 때문입니다.

## 결정

### 1. 안쪽을 하나로 합친다

`HomeCoverage` 가 나라별 판정을 하나로 합칩니다. 한국이 다뤘든 일본이 다뤘든 접할 기회가 있었던 것입니다.

부수 효과로 AND/OR 문제가 **사라집니다.** 판정 불가(`uncertain`, `no_data`)는 **안쪽 보도를 하나도 찾지 못했을 때만** 문제가 됩니다 — 이미 보도를 찾았으면 다른 나라의 판정 불가는 결론을 바꾸지 못합니다. ADR 0005 의 조건 4번("판정하지 못한 국가가 없어야 한다")이 불필요해졌습니다.

### 2. 이진 판정을 연속 격차로 바꾼다

```
exposure_gap = 바깥 독립 보도 블록 수 / (1 + 안쪽 기사 수)
```

| tier | 조건 |
|---|---|
| `absent` | 안쪽 보도 0건 — 접할 기회가 아예 없었다 |
| `underreported` | 안쪽에서 다뤘지만 격차가 기준 이상 |
| `comparable` | 안쪽 보도량이 바깥과 비슷하다 |
| `undecided` | 안쪽 보도를 못 찾았고 판정도 불가하다 |
| `insufficient_spread` | 바깥에서도 널리 다뤄지지 않았다 |

"아예 안 다뤄진 것"과 "적게 다뤄진 것"이 같은 축에 들어옵니다. 분자가 기사 수가 아니라 **블록 수**인 것은 P8·ADR 0004 와 같은 이유입니다. 분모의 `+1` 은 0 나눗셈을 막고 안쪽 1건과 0건의 차이를 과장하지 않습니다.

### 3. '외부에서 본 안쪽 이슈' 섹션을 만든다

격차의 **역방향**입니다. 내가 놓친 것을 찾는 게 아니라, 내 나라 이슈를 제3자가 어떤 틀로 쓰는지 봅니다. 안쪽에서 보는 것보다 객관적이라는 보장은 없지만, **이해관계가 다른 복수의 시선**이라는 점은 보장됩니다.

`comparable` 로 분류된 사건도 이 섹션에는 들어갑니다. 이미 접한 사건이어야 굴절을 볼 수 있기 때문입니다.

별칭 사전(ADR 0003)이 `south_korea` / `north_korea` / `japan` 을 추출하므로 새 기계가 필요 없습니다. `Cluster.entities` 로 걸러냅니다.

### 4. 안쪽 프레이밍을 비교표의 한 행으로 올린다

**설계 초기 원칙을 뒤집는 지점입니다.** 안쪽 매체를 브리핑 본문에서 의도적으로 뺐던 것(P6)은 누락 탐지에는 맞았지만, 굴절 탐지에서는 **안쪽 프레이밍이 바로 관찰 대상**입니다.

다른 블록과 나란히 놓고 "당신이 본 틀은 이것이었다"로 보여줍니다. LLM 요약을 거치지 않고 **원문 제목을 그대로** 인용합니다 — 안쪽 프레이밍은 요약하면 안 되는 대상입니다.

P6 에서 살아남는 부분: 안쪽 매체는 **바깥 보도 집계에 들어가지 않습니다.** `spread_score`, 블록 수, 클러스터링에 관여하지 않습니다. 비교표에만 등장합니다.

### 5. 소스 선택을 자국어판 우선으로 바꾼다

이것이 전제를 지키는 가장 중요한 변경입니다.

Global Times 영문판, TASS 영문판, France24 영문판은 **외국인 독자를 위해 쓰인 것**입니다. 대외 발신용으로 이미 정제되어 있습니다. 그것만 읽는 것은 바깥으로 나가는 게 아니라 **국내 필터를 수출용 필터로 바꾸는 것**입니다.

| 약함 (export) | 강함 (native) |
|---|---|
| France24 영문 | 르몽드 불어 |
| Global Times 영문 | 人民日報 중문 |
| TASS 영문 | 러시아어 원문 |

`spikes/candidates.tsv` 에 `priority` 열을 추가했습니다 — `native` / `export` / `baseline`. 후보 55건 중 native 38, export 11 입니다. latam·africa 블록도 추가했습니다 ("무슨 주제가 됐든"에 대응).

`probe_sources.py` 는 사용 가능 소스 중 export 가 native 보다 많으면 경고합니다.

## 결과

**좋은 점.** 제품이 사용자가 실제로 말한 문제에 대응합니다. 이진 목록이 아니라 정도의 문제가 되어, 임계값 하나에 결과가 좌우되지 않습니다. 가장 가치 있는 섹션(외부에서 본 안쪽 이슈)이 기존 기계로 공짜에 가깝게 나옵니다.

**비용.** Phase 0 난이도가 올라갑니다. 자국어판 피드 URL 을 찾는 것이 영문판보다 어렵고, 비영어 리드의 번역 비용이 생깁니다. 파이프라인은 이미 언어 불특정이므로(다국어 임베딩, 원어 보존) 코드 변경은 아닙니다 — 조사 범위의 문제입니다.

**정직한 천장.** 이 도구는 필터를 **제거하지 못합니다. 하나 더 추가합니다.** 영어권 웹으로 학습된 모델이 외국 언론을 읽어 정리하는 것이니까요. 정직하게 주장할 수 있는 것은 두 가지뿐입니다.

1. 원문 단어를 **원어 그대로** 눈앞에 놓는다. 번역으로 대체하지 않는다.
2. 어디서 갈라지는지 알려줘서, 원문을 직접 읽을 지점을 찾아준다.

즉 **날것 그 자체가 아니라 날것으로 가는 색인**입니다. 모든 항목에 원문 링크를 붙이고 판정은 하지 않습니다. 그리고 제목+리드는 얇은 층이며, 제목은 기사에서 가장 편집된 부분입니다. RSS 기반 "날것"은 약한 날것입니다.

**측정할 수 없는 것.** 무엇을 보여줄지 **고르는 단계의 편향**입니다. M2 는 한 클러스터 안에서 앵글로권을 과대 인용하는지는 재지만, 어떤 클러스터가 상위에 뽑히는지는 재지 않습니다. 현재 측정 수단이 없습니다. 뚫린 구멍으로 남겨 둡니다.
