# ADR 0001 — Phase 0: 소스 선정

- 상태: **진행 중** (조사 미실시)
- 날짜: 2026-11-04

## 맥락

후보 소스 30개(해외 27 + baseline 3)를 `spikes/candidates.tsv` 에 두었습니다. 이 목록은 **검증되지 않았습니다.** 상당수는 RSS 를 폐지했거나, 리드 없이 제목만 주거나, 봇을 차단하거나, 이용약관이 자동 수집을 금지할 것으로 예상됩니다.

후보 목록을 작성한 환경에서는 외부 호스트가 네트워크 정책으로 전부 차단되어 단 한 건도 실측하지 못했습니다. 따라서 이 ADR 은 결론이 아니라 조사 계획입니다.

## 결정

조사 전까지 파이프라인 코드를 작성하지 않습니다. 소스가 실제로 무엇을 주는지 모르는 상태에서 쓴 수집·클러스터링 코드는 버려지기 때문입니다.

목표 규모는 **해외 소스 8~14개, 블록 4개 이상**입니다. 20개를 채우려 무리하지 않습니다. 리드를 제대로 주는 소스 10개가 제목만 주는 소스 20개보다 낫습니다.

## 미해결 질문 (사용자 판단 필요)

1. **Guardian Open Platform 이 본문까지 무료로 제공한다면 어떻게 할 것인가?**
   P8(본문 저장 금지)과 "리드가 빈 소스를 보완할 유일한 합법 경로" 사이에 긴장이 있습니다.
   기본 방침은 *제공되더라도 저장하지 않고 리드 길이로 잘라 쓴다* 입니다. 확정 필요.

2. **GDELT 를 개별 피드의 대체로 쓸 것인가, 보완으로만 쓸 것인가?**
   블록별 커버리지 집계를 피드 없이 얻을 수 있다면 수집 부담이 크게 줄지만,
   원문 리드를 못 얻으면 프레이밍 대조표를 만들 수 없습니다.

3. **국가통제 매체를 몇 곳까지 넣을 것인가?**
   P4 에 따라 라벨을 붙여 포함하지만, 비중이 커지면 "선전 모음집"이 됩니다.
   해외 소스 중 `state_controlled` 비율의 상한을 정할 필요가 있습니다.

4. **남미·아프리카 소스를 찾을 것인가?**
   현재 후보는 블록 7개를 커버하지만 latam·africa 가 비어 있습니다.
   "세계가 어떻게 돌아가는지"의 공백은 오히려 이쪽일 가능성이 큽니다.
