# Blindspot4KRJP

전 세계 주요 언론의 당일 보도를 수집해 ① 같은 사건을 각국이 **어떻게 다르게** 서술하는지의 대조표와, ② 세계가 크게 다루는데 **한국·일본 언론은 다루지 않은** 이슈 목록(보도 공백)을 만드는 파이프라인입니다.

> **현재 상태**
> - Phase 0 (소스 접근성 검증): **미실시.** 후보 30개 중 한 건도 실측하지 못했습니다 (작성 환경에서 외부 호스트가 네트워크 정책으로 전부 차단).
> - Phase 1 (수집 → 클러스터링 → 보도 공백): **골격 구현.** 수집 어댑터, 전재 축약, 클러스터링, 공백 판정, 렌더링이 동작하며 합성 데이터로 종단 확인됨. 실제 피드와 임베딩 모델이 붙지 않았습니다.
>
> 합성 데이터로 브리핑 한 부를 생성해 볼 수 있습니다 (네트워크·API 키·비용 0):
>
> ```bash
> python scripts/demo_briefing.py
> ```

## 이 프로젝트가 하지 않는 것

AI 가 여러 언론의 보도를 종합해 "중립적이고 객관적인 의견"을 내놓는 것 — 이것을 **의도적으로 하지 않습니다.**

이유는 세 가지입니다.

1. **평균은 객관이 아닙니다.** 20개 매체의 논조를 섞으면 중립이 아니라 무색무취한 평균이 나옵니다. 사안에 따라 그 평균은 왜곡입니다.
2. **심판이 당사자입니다.** 영어권 웹으로 학습된 모델에게 중립 판정을 맡기면, 눈에 보이는 편향을 눈에 안 보이는 영미권 편향으로 교체하게 됩니다. 이 프로젝트는 그 편향을 지표 M2 로 감시합니다.
3. **AI 가 생성한 "객관적 의견"은 반증이 불가능합니다.** 신뢰할 근거가 없습니다.

그래서 AI 의 역할은 결론을 내리는 것이 아니라 **차이를 보이게** 하는 것입니다. 판단은 독자가 합니다. 이 제약은 문서상의 약속이 아니라 타입과 테스트로 강제됩니다 (아래 참조).

## 설계 원칙이 코드에서 강제되는 방식

| 원칙 | 강제 지점 |
|---|---|
| 종합 의견을 생성하지 않는다 | `ClusterAnalysis` 에 해당 필드가 없음 + `tests/test_p1_no_conclusion_fields.py` 가 `src/` 전체를 스캔 |
| 모든 주장은 출처를 갖는다 | `Claim.article_ids` 가 `min_length=1`; `provenance.validate()` 가 미검증 주장을 제거하고 비율을 보고 |
| "공통 사실"은 계산 결과다 | `derive.shared_facts()` — LLM 출력 필드가 아니라 집합 연산 |
| 정치성향 라벨에 근거가 필요하다 | `SourceProfile` 의 `model_validator` 가 `lean_basis` 없는 라벨을 거부 |
| 본문을 저장하지 않는다 | `Article` 에 본문 필드가 없음 + 테스트가 검사 |
| 측정하지 않은 값을 적지 않는다 | `FeedConfig` 의 실측 필드 기본값이 `None` + 테스트가 검사 |
| 한국·일본 매체는 브리핑에 들어가지 않는다 | `cluster.build_clusters()` 가 `role=baseline` 기사를 받으면 예외 |
| 통신사 전재가 블록 수를 부풀리지 않는다 | `dedupe` 가 전재를 한 건으로 묶고, 가장 먼저 발행된 기사의 블록에만 귀속 |

## 보도 공백을 판정하는 방법

한국어 기사가 해외 클러스터에 "묶이기"를 요구하지 **않습니다.** 교차언어 임베딩에서 매칭에 실패할 가능성이 가장 높은 것이 한국어 기사이므로, 그 방식은 클러스터링 실패를 그대로 거짓 공백으로 바꿔 지표를 한 방향으로 부풀립니다.

대신 **비대칭 검색**을 씁니다. 자세한 근거는 [ADR 0002](docs/decisions/0002-asymmetric-baseline-retrieval.md).

- 클러스터는 해외 소스만으로 만들고, 그 대표 문장으로 한국어 코퍼스를 **질의**합니다.
- baseline 쪽은 시간 윈도우를 더 넓게(72h vs 36h) 둡니다 — 한국 보도는 흔히 지연됩니다.
- 임베딩 외에 **숫자·연도**(언어 독립 신호)와 **개체 별칭**을 섞습니다.
- 판정은 3분기이고, **애매한 구간은 공백으로 세지 않습니다.** 조용히 놓치는 쪽이 틀리게 주장하는 쪽보다 낫습니다.

## 측정

아직 측정된 수치가 없습니다. 측정 설계만 되어 있습니다.

| 지표 | 내용 | 상태 |
|---|---|---|
| M1 `unsupported_claim_rate` | 출처 검증에 실패해 폐기된 주장 비율 | 로직 구현됨, 실측 전 |
| M2 `anglo_amplification` | 인용된 앵글로권 비율 − 입력 앵글로권 비율. 양수면 과대 인용 | 로직 구현됨, 실측 전 |
| M3 `reproducibility` | 동일 입력 반복 시 사실 주장 집합의 Jaccard | 미구현 |
| M4 공백 정밀도·재현율 | 손 라벨 대조. `eval/gap_calibration.py` | 하네스 구현됨, 라벨 없음 |

**임계값은 전부 미보정입니다.** `config.yaml` 의 값은 측정된 값이 아니라 출발점입니다. 보정 전에는 공백 건수를 공개 지표로 쓰지 않습니다.

## 개발

```bash
pip install -e ".[dev]"
pytest -q
```

테스트는 네트워크와 API 키를 쓰지 않으며 비용이 들지 않습니다. 외부 호출은 전부 주입된 가짜 함수와 고정 fixture 로 대체됩니다.

합성 데이터 종단 확인 (파이프라인이 연결되어 돌아가는지):

```bash
python scripts/demo_briefing.py
```

소스 접근성 조사:

```bash
python spikes/probe_sources.py --only bbc_world,dw_en
```

조사 대상 호스트가 방화벽·프록시 정책으로 막혀 있으면 스크립트가 이를 사이트 장애와 구분해 보고합니다. 그 경우 재시도하지 말고 허용 도메인에 추가하십시오.

## 수집·발행 방침

- 저장: 제목 + 리드 + URL + 시각 + 언어. **본문은 수집·저장하지 않습니다.**
- RSS 와 공식 API 만 사용합니다. 헤드리스 브라우저, 유료장벽 우회, robots.txt 무시를 하지 않습니다.
- 발행물은 기사당 인용을 짧게 유지하고, 원문 링크와 "AI 가 생성한 분석" 표시를 반드시 포함합니다.
- 테스트 fixture 의 기사 발췌는 출처와 수집일을 명기하며 재배포 대상이 아닙니다.

## 선행 작업과의 관계

[Ground News](https://ground.news), AllSides 등은 **한 나라 안의 좌-우** 보도 비교를 제공합니다. 이 프로젝트는 **국가 간** 비교와, 한국어·일본어 사용자 기준의 **보도 공백** 탐지를 다룹니다.

같은 제작자의 [Neutralize4KRJP](https://github.com/fairyofdata/Neutralize4KRJP) 는 한·일 두 매체로 중립 기사를 합성하는 실험이었고, 그 저장소의 「한계」 섹션에 적힌 "중립성을 측정하지 않았다"가 이 프로젝트의 출발점입니다. 설계 판단 세 가지(구조화 출력, 파이프라인/UI 분리, 비용 0 테스트)는 계승하고, "LLM 이 중립 결론을 쓴다"는 전제는 버렸습니다.
